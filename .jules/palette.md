# Palette's Journal

## 2025-05-18 - Keyboard Navigation with Skip Link & Focus Rings
**Learning:** Single-page landing applications with prominent fixed navigation headers lack quick keyboard accessibility to the primary content landmark, forcing keyboard and assistive tech users to tab through entire link lists and action bars.
**Action:** Always provide a visually hidden skip-to-content link positioned above navigation landmarks that slides into view on `:focus-visible`, paired with distinct theme-aware `:focus-visible` outline rings across interactive controls.
